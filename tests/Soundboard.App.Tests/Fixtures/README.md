# Audio fixture provenance

`tiny-vorbis.ogg` is the 4,225-byte `TestFiles/1test.ogg` fixture from the
official [NVorbis repository](https://github.com/NVorbis/NVorbis). It is used
only to verify NVorbis 0.10.5 decoding and is redistributed under that
repository's MIT license. Its SHA-256 is
`9E11F3008B507327B788D6FE20D54DE97E95A068BFCE00E6A79033C8E1C77646`.
The license text is included as `NVorbis-LICENSE.txt`.

Ogg Opus fixtures are generated in the test harness with the managed
Concentus and Concentus.Oggfile APIs. No FFmpeg executable is required.
