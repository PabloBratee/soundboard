# Security Policy

## Supported versions

Security fixes are currently considered for the `1.0.x` release line.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue. Prefer
GitHub's private security advisory workflow for this repository when it is
available. Otherwise, contact the maintainer through the
[PabloBratee GitHub profile](https://github.com/PabloBratee).

Never include user audio, library or settings files, Windows audio device IDs,
credentials, access tokens, private keys, or other personal data in a report.
Use minimal synthetic examples where reproduction material is necessary.

This is a personal project, so no response time or resolution deadline is
guaranteed.
